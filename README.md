# avatar-muse-connector

アバターアプリ（声・口パク・表情の「身体」）を、あなたの自分の **MUSE**（脳）に
つなぐための MCP コネクタです。脳は汎用の AI ではなく、あなたのことを知っている
あなたの MUSE 本人です。キャラ側は出力（喋る・聞く・見せる）だけを担います。

このプラグインは、ユーザーが自分で導入する「事前承認済みの経路」です。
接続のために、ウェブの応答文にしたがってプログラムを取得・実行するような
手順は使いません。必要なプログラムはすべてこのリポジトリに同梱されています。

## 仕組み（v2）

- **ステージ**（スマホのアプリ画面）が発話を中継へ送る
- **中継**（avatar-relay2）はユーザーごとの「部屋」を持ち、発話は回答される
  まで保持される（脳が落ちていても発話は消えない）
- **脳デーモン**（同梱の `brain.py`）が中継と WebSocket で**常時接続**し、
  発話の即時受け取り・相槌・VOICEVOX 合成・キャラ固定ボイスの決定を担う。
  接続中は音声エンジンを温かいまま保ち、切断時は短い間隔で再接続する
  （常時接続＝ラグなし、が設計の核）
- **この MCP サーバー**は、デーモンのローカル API の上に被せる薄い層。
  MUSE は道具（listen / say）経由で会話する

## つなぎ方（番号を伝えるだけ、JSON は触りません）

### 1. プラグインを MUSE に追加する

このリポジトリを手元に置き、MCP サーバーを登録します（パスは自分の環境に
合わせてください）:

```json
{
  "mcpServers": {
    "avatar-muse": {
      "command": "python3",
      "args": ["<このリポジトリの場所>/avatar_mcp_server.py"]
    }
  }
}
```

### 2. アプリで番号を出す

アバターアプリの初回画面で「MUSEとつなぐ」を押すと、番号と伝える文
（「アバターとつないで。番号は 123456」）が表示されます。

### 3. 自分の MUSE に番号を伝える

その文を、そのまま自分の MUSE に言うだけです。ファイルの受け渡しは
ありません。MUSE 側では次が実行されます：

```
python3 pair_claim.py 123456
```

接続情報は `~/.avatar2/config.json` に保存されます（権限600、
脳キーが画面に表示されることはありません）。
番号の有効期限は10分です。期限切れのときは、アプリで新しい番号を
出し直してください。

### 4. 脳デーモンを常駐させる（一度だけ）

```
python3 brain.py run
```

デーモンが中継に接続すると、アプリに「つながりました」と表示されます。
デーモンは常駐し続けます。再起動した場合は、もう一度このコマンドを
実行してください。

### 5. 会話する

以後は `avatar_listen` で発話を受け、`avatar_say` で返す往復で会話します。
朝の報告や予定の読み上げも、アバター経由で話せるようになります。

## MUSE が使える道具

| 道具 | 役割 |
|---|---|
| `avatar_listen` | ユーザーの次の発話を待って返す（id・本文・キャラ・呼び名・位置情報つき） |
| `avatar_say` | 喋らせる。発話への回答は `utterance_id` 付き（声は発話のキャラで自動決定、同じ id への複数回は続き）／無しは通知発声 |
| `avatar_report` | 報告形式で、短い文の列を順に読み上げる |
| `avatar_status` | デーモンの起動・接続・エンジン・未処理発話数の確認 |

会話は双方向です。使い方の作法は同梱スキル `skills/avatar-companion/` に
入っています。返答の速さのコツは「最初の一文を先に `avatar_say` し、
続きを同じ `utterance_id` で送る」ことです（デーモンが文単位で合成して
先行送信します）。

## 前提

- Python 3（追加ライブラリは不要。標準ライブラリだけで動きます）
- VOICEVOX Engine（声の合成に使用）。場所は環境変数 `AVATAR2_ENGINE_DIR`
  で指定できます
- 脳デーモン（`brain.py run`）が起動していること

## 正直な制約

- 背景の切り替えは v2 では脳側の道具にありません。背景はアプリ側
  （ガチャ／コレクション）で選ぶものです。
- 声はキャラごとに固定で、道具側から話者を選ぶことはできません
  （キャラと声の食い違いを構造的に防ぐため）。
- 接続情報（脳キー）は各自の端末の中だけに置かれます
  （`~/.avatar2/config.json`、権限600）。このリポジトリにキーは含まれません。
- 頭脳（MUSE）の契約はユーザー側です。このコネクタは出力と接続の
  受け口だけを担います。
