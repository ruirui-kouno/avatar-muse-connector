# avatar-muse-connector

アバターアプリ（声・口パク・表情の「身体」）を、あなたの自分の **MUSE**（脳）に
つなぐための MCP コネクタです。脳は汎用の AI ではなく、あなたのことを知っている
あなたの MUSE 本人です。キャラ側は出力（喋る・聞く・見せる）だけを担います。

## つなぎ方（3ステップ、JSON は触りません）

1. **接続ファイルを作る**
   ```
   python3 pair.py
   ```
   ペアリングコード（6桁）と接続ファイルが自動で作られます。
   アクセスキーが画面に表示されることはありません。

2. **自分の MUSE に追加する**
   生成された `muse-connector.json` を、MUSE のカスタムコネクタとして
   追加してください（ファイルの中身を編集する必要はありません）。

3. **接続テスト**
   MUSE に「アバターで接続テストをして」と言うだけ。
   アバターが一言喋れば完了です。以後は朝の報告や予定の読み上げを
   アバター経由で話せるようになります。

## MUSE が使える道具

| 道具 | 役割 |
|---|---|
| `avatar_say` | 一言〜短い文を喋る（表情指定つき） |
| `avatar_listen` | ユーザーの次の発話を待って、文字起こしテキストで返す |
| `avatar_report` | 報告形式で喋る＋「本日の重点」パネル表示 |
| `avatar_set_background` | 背景を切り替える（会議室／社長室／夜景） |
| `avatar_status` | 接続とキャラの状態確認 |

会話は双方向です。MUSE は `avatar_say` → `avatar_listen` の往復で
会話を回します。使い方の作法は同梱スキル `skills/avatar-companion/` に
入っています。

## 前提

- アバター側ブリッジ（bridge_server.py）が動いていること
- Python 3（追加ライブラリは不要。標準ライブラリだけで動きます）

## 正直な制約

- `avatar_set_background` は切替イベントを接続中ステージへ配信しますが、
  ステージ側の背景イベント受信は今後の対応項目です（現行ステージは
  画面のボタンで背景を切り替えます）。
- アクセスキーは各自のPCの中だけに置かれます（`config.local.json`、
  権限600）。このリポジトリにキーは含まれません。
- 頭脳（MUSE）の契約はユーザー側です。このコネクタは出力と接続の
  受け口だけを担います。
